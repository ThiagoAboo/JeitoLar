# JeitoLar
JeitoLar oferece serviços de reparos, instalações e manutenção residencial, com atendimento no local. Realizamos pequenos reparos elétricos e hidráulicos, instalação de chuveiros, luminárias, ventiladores, suportes de TV, prateleiras, cortinas e persianas, montagem de móveis e diversos serviços de faz-tudo para sua casa.
